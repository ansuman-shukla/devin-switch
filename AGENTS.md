# Verification and runtime constraints

- Run `make lint` and `make test`. Set `DS_TEST_NATIVE=/Applications/Devin.app/Contents/Resources/app/extensions/windsurf/devin/bin/devin` when running tests to also check compatibility with the installed CLI, using an isolated temporary database and no model requests.
- Typecheck the Mac UI with `swiftc -typecheck -parse-as-library -target arm64-apple-macos14.0 -framework SwiftUI -framework AppKit macos/DevinSwitch.swift macos/AccountViews.swift` on Apple Silicon.
- When building from inside a `ds` session, use `env -u XDG_DATA_HOME -u XDG_CONFIG_HOME -u XDG_CACHE_HOME -u XDG_STATE_HOME make app`. Otherwise uv's tool installation can end up inside the current account's private data directory instead of the stable user-level installation.
- Keep `--reinstall-package devin-switch` in the app install target: `uv tool install --force .` alone can reuse a cached wheel after Python source-only changes. Verify installed modules, not just the source-tree tests.
- A nested CLI can inherit `CHISEL_SESSION_DB`. Keep the native environment explicitly pinned to Switch's shared database; XDG isolation alone is insufficient.
- Runtime leases must survive into the native child via `pass_fds`. Release them by closing descriptors, not by explicitly unlocking a descriptor shared with a still-running child.
- The saved default profile and the profile bound to an open CLI process are different concepts. Never silently change the latter when updating the default.
- Session tracking covers wrapper launches, not in-terminal `/new` or `/resume` changes. Do not label process liveness as agent activity or guess which newly created conversation belongs to a process.
- `!ds switch` is a one-command handoff: refresh usage, rank other saved logins by the minimum remaining percentage across applicable daily/weekly quotas, then close and resume automatically. Unknown/stale/exhausted usage is not eligible for automatic selection. Do not hold the global store lock during network refresh. Manage the `SessionEnd` hook in the isolated account's CLI config, preserving JSONC comments and existing hooks; never require or modify project configuration. Accept only the final `prompt_input_exit` receipt, never latest-history or the launch ID as a fallback. Keep receipts separate from launch metadata. Missing receipts and abnormal exits must not restart. A handoff updates the shared default only after the destination CLI process is created successfully, under the store lock; never select at queue time or revert it when that chat later closes. Normal `ds run --account` launches remain one-off overrides. Do not replay prompts, retarget other open processes, or drop sandbox/permission flags. Custom `--config` launches stay passthrough-only. Isolate inherited `DS_RUN_ID`, `DS_EXECUTABLE`, and `DS_FROZEN` in tests.
- The terminal relay waits for the switch command to finish, sends separate Escape and Ctrl+D keys to its own child PTY, and cancels on timeout without force-killing. Test it with a real PTY and a fake CLI, including terminal settings restoration. macOS may set the transient `PENDIN` flag on canonical-mode restoration; ignore only that kernel-managed flag when comparing terminal settings.
- Portable builds use `make dmg` and `make smoke-app`; audit wheels and source archives with `uv run --locked python scripts/check_dist.py` after `make build`. These checks use temporary state, not real accounts.
- Keep the PyInstaller runtime under `Contents/Resources/ds-runtime`, not `Contents/Helpers`: the latter makes macOS code signing interpret its data files as nested code. The frozen launcher must invoke its executable directly, without Python's `-m` arguments.
- Run `actionlint` when changing GitHub workflows. Release tags create drafts only after the reusable CI workflow passes; Apple Developer ID signing and notarization are not configured.
- On macOS, `make test` also compiles and runs `tests/AppModelTests.swift` via `tests/test_macos.py`, using an injected offline bridge and isolated preferences. The row-label regression renders SwiftUI controls and uses on-device Vision text recognition to check visible captions, including disabled states, without changing their layout. Keep refresh timers owned by `AppModel`, not recreated SwiftUI views, and keep background polling separate from user-action busy state.
- Display names are cosmetic, stored atomically in each account's `display-name.json`. Keep the strict legacy `account.json` schema untouched so already-running older wrappers can still read it. Never rename account directories, selection pointers, leases, or session records when editing a display name; use the stable alias for every action.
- Global quota is an explicitly labeled equal-weight average of per-account percentages, separately for daily and weekly windows; absolute plan capacities are not available. Include exhausted accounts as zero, exclude stale/missing/signed-out readings, and report coverage and not-applicable windows. Match the CLI's 120-second freshness limit and reject expired resets. Never add daily and weekly allowances together or call the result a shared balance.
- The Mac workspace supports a 640×520 minimum, a persistent 56-point collapsed sidebar rail, and bounded adjustable sidebar widths. Responsive grids must cap their column count at the number of items. Capture full scrollable layouts with `NSHostingView` in native tests: `ImageRenderer` alone does not render embedded native scroll views. Native mouse-event tests need a temporary, key, titled test window; hidden windows do not dispatch control clicks reliably. Keep these windows on the injected offline bridge and isolated preferences.
- Global quota represents currently usable allowances: exhaustion in either applicable window contributes zero to both daily and weekly averages, retaining the account in each applicable denominator. Validate both applicable windows before including an account; an unknown, invalid, or expired companion window must not imply availability. Not-applicable windows do not block the other allowance, and per-account meters retain their raw readings.
